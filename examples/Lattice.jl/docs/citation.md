# Citation

`Lattice.jl` is an example project with no publication behind it, so there is nothing
to cite. The entry below shows the shape a real one would take.

```bibtex
@software{example_lattice_jl,
  author = {Example Lab},
  title  = {Lattice.jl},
  year   = {2026},
  url    = {https://github.com/example/Lattice.jl}
}
```

!!! warning "Nothing here is a real identifier"
    A DOI or an arXiv number belongs on a page like this only once it exists. The
    method notes linked from the home page are illustrative too.

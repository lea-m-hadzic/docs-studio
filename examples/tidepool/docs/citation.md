# Citation

`tidepool` is an example project with no publication behind it, so there is nothing to
cite. The entry below shows the shape a real one would take.

```bibtex
@software{example_tidepool,
  author = {Example Lab},
  title  = {tidepool},
  year   = {2026},
  url    = {https://github.com/example/tidepool}
}
```

!!! warning "Nothing here is a real identifier"
    A DOI or an arXiv number belongs on a page like this only once it exists. The
    checker that ships with `docs-studio` does not invent them, and neither should a
    maintainer in a hurry.

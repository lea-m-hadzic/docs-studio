# Example sites

Three sites generated by `docs-studio`, kept here so the toolkit's output can be read
and built without generating anything first. Each was created with `docs-studio init`
and then had its pages written, exactly as a maintainer would.

| site | language profile | palette | branding |
| --- | --- | --- | --- |
| [`tidepool/`](tidepool) | `python` | `ocean-violet` | generated monogram |
| [`Lattice.jl/`](Lattice.jl) | `julia` | `indigo-lavender` | supplied SVG, with a dark variant |
| [`greenline/`](greenline) | `generic` | `neutral` | generated monogram, custom initials |

**The three projects are fictional.** They exist to exercise the generator, and the
third one is deliberately nothing like the two research sites the design language came
from — that is what shows the toolkit is not wired to them. Nothing on these pages is a
real result, a real API or a real publication.

To build one:

```bash
pip install "zensical==0.0.67"
cd examples/tidepool
docs-studio check
zensical serve
```

# Welcome to docs-studio! { .ds-home-title }

[:simple-github: GitHub Repository](https://github.com/lea-m-hadzic/docs-studio){ .md-button aria-label="GitHub Repository" }
[:material-web: Zensical](https://zensical.org){ .md-button aria-label="Zensical" }
{ .ds-resources }

**Generate polished Zensical documentation sites from one config file.**

`docs-studio` scaffolds a documentation site that looks finished on the first build:
semantic colour tokens mapped onto the theme's own variables, a hairline above each
section, a wider article beside a narrow "On this page", compact outlined resource
buttons, and matching light and dark schemes that are checked against WCAG AA before
any file is written.

The design language is not invented. It is extracted from two documentation sites that
are in production, and generalized — see
[Where the design came from](comparative-analysis.md).

A generated site makes **no third-party requests**: system fonts, no CDN, no web font,
no maths renderer.

Built by Lea M. Hadzic.

[Quickstart](quickstart.md){ .md-button .md-button--primary }
[Installation](install.md){ .md-button }

```bash
docs-studio init my-docs --name my-package --preset ocean-violet --yes
cd my-docs && docs-studio check && zensical serve
```

!!! info "This site documents itself"
    Everything you are reading was generated by `docs-studio init` from
    [`docs-studio.toml`](configuration.md) in the repository root, with this palette
    supplied as a file and these marks supplied as SVGs. The same
    [`check`](check.md) and [`update`](update.md) that run against your project run
    against this one.

## What it gives you

<div class="grid cards" markdown>

-   **A site you do not have to style**

    ---

    One palette choice and a logo, and the result carries the proportions, the
    component recipes and the two colour schemes of a site someone already finished.
    See [Palettes](palettes.md).

-   **An update that cannot eat your work**

    ---

    Every generated file is recorded with a checksum and an owner. Change the palette
    a year later and the styling is regenerated while your pages, your artwork and
    your CSS are left exactly as they are.
    See [Safe updates](updating.md).

</div>

## Scope

!!! warning "A scaffolder, not a framework"
    `docs-studio` generates files and then gets out of the way. It is not a plugin
    system, a theme, or a runtime: the site it produces is an ordinary
    [Zensical](https://zensical.org) project that builds without `docs-studio`
    installed at all.

One docs directory, one site. No multi-version documentation, no internationalization,
no blog, no API-documentation extraction. Those are Zensical features or plugins; the
toolkit does not generate configuration for them.
